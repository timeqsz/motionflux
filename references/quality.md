# 时间、组合与画面检查

需要做组合或修复视觉问题时读本页；沿用调用方的制作流程，不把动效素材任务扩大成整片制作。

## 先建立有用途的主体

从实际用途选择元素，例如赛事队名与比分、唱片与曲名、产品轮廓与卖点。先把静态构图、字号、边缘和中心排好，再用原子改变这些对象。短段通常先选 2–3 种有明确职责的动作；数量不是引擎限制，不为凑数叠加效果。

不同用途要有不同的进入、停留、离开方式。替换内容时也重算布局与时间，不只换颜色。不要让每个案例都套相同的遮板开场、统一淡出或强制倒放。

## 时间与循环

- 渲染使用显式帧号或秒数。固定随机 seed、主体 id 和资产；从基础状态求值，不依赖上一帧。先验证同一帧重复、乱序取样得到相同状态。
- 30 fps 的 5 秒是 150 帧，编码索引为 0–149；终态边界 150 可用于比较，但不是额外一帧。动作要提前留出可见终态时长时，缩短动作片段并保留尾段，别提前截掉动作来凑周期。
- 有限入场／退场和连续运动分开处理。不要用 `frame % 90` 把还没完成的整段切断，也不要用全局 ping-pong 把所有动作倒放。
- 整数圈数不等于整幅画面无缝：逐一比较首尾的轮廓、透明度、纹理相位和速度。噪声、碎裂、粒子要看实际实现。若本来就是单次入场，保持终态或按叙事转入下一镜，不必强行循环。
- 网页预览可按实际时间跳过计算跟不上显示的帧；成片按每个目标帧完整求值和编码。提高播放 fps 或重复已有帧不会修复原素材卡顿。
- 阅读时间取决于文本长度和画面变化。让关键信息停稳后才计入可阅读时间；以目标显示尺寸实际读一遍，避免长空停与来不及看清。

## 对齐、层级和遮罩

- 二维点围绕自己的原点定义；旋转／缩放绕该原点。一个徽记、字标和圆盘属于同一主体时，共用枢轴和变换，不能独立猜中心。
- 文本坐标是首行左侧基线。用实际字体的 `measureText` 检查宽度、ascent、descent 与多行间距；字体加载完成后测量。不要把字符数估计当最终排版。
- Canvas 后画覆盖先画；MotionSpec 按 `nodes` 顺序绘制，没有 CSS z-index。先画背景与远景，再画实体、前景与文字。需要遮挡时必须有不透明填充或真实 mask，只改顺序不会让空心轮廓遮住后景。
- MotionSpec 没有 group 字段。复杂主体由宿主统一坐标变换和裁剪；几何输出中的 `clip` 使用随包 `drawAtom` 实现。自绘图片需要宿主自己的遮罩，不能把任意图片塞入 path 节点。
- 画幅变化后检查完整主体、文字与发光边缘。图形变换用等比缩放；主体与文字不要因卡片宽高变化被拉伸。

## 验收对象是输出画面

检查入场中间帧、停稳帧、退场中间帧、片段两侧与循环接缝。优先看曾出问题的位置：文字基线、徽记圆心、旋转轴、前景遮罩、快速位移和边缘裁切。

交付视频时从编码后的文件抽帧，并真实播放受影响的完整段落；网页或画布预览不能替代编码验证。`render` 的 `verified`、状态数值测试、技能格式校验各有用途，都不等于视觉验收。记录实际看过的文件与范围；没有声音就说明无音轨，不补写没有制作的旁白或字幕。
